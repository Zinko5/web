Configuración y uso de lenguajes (Terminal)
C# (.NET)
A diferencia de scripts simples, C# requiere una estructura de proyecto para gestionar dependencias y compilación.

# Crear un nuevo proyecto de consola dotnet new console -n MiProyecto # Entrar a la carpeta y ejecutar el proyecto cd MiProyecto
dotnet run # Crear el ejecutable (compilar) dotnet build # Publicar como ejecutable único para Linux dotnet publish -c Release -r linux-x64 --self-contained
Python 3
Es recomendable usar entornos virtuales (venv) para no ensuciar las librerías del sistema.
# Crear el entorno virtual python3 -m venv .venv # Activar el entorno source .venv/bin/activate # Instalar librerías pip install nombre_libreria # Guardar librerías instaladas en un archivo pip freeze > requirements.txt # Instalar librerías desde un archivo pip install -r requirements.txt # Salir del entorno virtual deactivate # Levantar un servidor web rápido en el puerto 8000 python3 -m http.server 8000 # Abrir el servidor en un directorio concreto python3 -m http.server 8000 --directory /ruta/a/tu/carpeta
Java
Para proyectos Java, se recomienda organizar el código en carpetas y usar nombres de clase que coincidan con el archivo.

# Estructura recomendada: CarpetaProyecto/src/Principal.java

# Compilar el proyecto (enviando el resultado a la carpeta bin) javac -d bin src/*.java # Ejecutar el proyecto desde la carpeta bin java -cp bin Principal # Listar versiones de Java instaladas sudo update-alternatives --display java # Cambiar la versión por defecto de Java sudo update-alternatives --config java
R (Configuración para VSCode)
Para que R funcione correctamente en VSCode y tenga mejores visualizaciones, sigue estos pasos:
# Abrir R en la terminal y ejecutar: install.packages("languageserver")
install.packages("httpgd") # Configuración en VSCode:
1. Instala la extensión "R" de REditorSupport.
2. Ve a Ajustes (Ctrl + ,) y busca r.plot.useHttpgd.
3. Activa la casilla para que los gráficos salgan en una ventana interactiva y redimensionable en VSCode.
# Alternativa para ventana externa en Linux: En el script de R, usa el comando X11() antes de graficar.
